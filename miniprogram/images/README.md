# 小程序图片资源说明

## 需要准备的图片文件

请将以下图片文件放置在 `miniprogram/images/` 目录下：

### 基础图标 (32x32px)
- `home.png` - 首页图标
- `home-active.png` - 首页激活图标
- `store.png` - 门店图标
- `store-active.png` - 门店激活图标
- `order.png` - 订单图标
- `order-active.png` - 订单激活图标
- `profile.png` - 个人中心图标
- `profile-active.png` - 个人中心激活图标

### 功能图标 (64x64px)
- `icon-book.png` - 预订图标
- `icon-unlock.png` - 开锁图标
- `icon-member.png` - 会员图标
- `icon-service.png` - 客服图标
- `search.png` - 搜索图标
- `close.png` - 关闭图标
- `location.png` - 定位图标

### 特色图标 (80x80px)
- `feature-24h.png` - 24小时图标
- `feature-smart.png` - 智能图标
- `feature-clean.png` - 清洁图标
- `icon-fast.png` - 快速图标
- `icon-safe.png` - 安全图标

### 其他图片
- `logo.png` (120x120px) - 应用Logo
- `wechat.png` (40x40px) - 微信图标
- `banner1.jpg` (750x400px) - 轮播图1
- `banner2.jpg` (750x400px) - 轮播图2
- `default-store.jpg` (300x300px) - 默认门店图片
- `empty.png` (120x120px) - 空状态图标

## 图片规范
- 格式：PNG (图标) / JPG (照片)
- 尺寸：按照标注尺寸制作，支持2倍图
- 命名：使用小写字母和连字符
- 优化：压缩图片大小，保证清晰度

## 临时解决方案
如果暂时没有图片资源，可以：
1. 使用微信小程序内置图标
2. 使用纯色背景代替
3. 从免费图标库下载（如 iconfont.cn）
