# DeepSeek 小说生成器项目经验总结

## 项目概述
使用 DeepSeek API 创建自动化小说生成工具，支持目录生成和章节内容创作。

## 技术栈选择

### 最终方案：Python
- ✅ 完美支持 UTF-8 编码
- ✅ 丰富的 HTTP 库支持
- ✅ JSON 处理简单可靠
- ✅ 跨平台兼容性好

### 尝试过的方案

#### PowerShell (❌ 失败)
**问题**：
- 中文编码支持差
- 脚本解析错误
- 字符串处理复杂

#### 批处理 + curl (❌ 部分成功)
**问题**：
- 编码转换困难
- 错误处理不完善
- 可视化效果差

## 核心技术难点

### 1. 编码问题解决
```python
# 关键配置
headers = {
    "Authorization": f"Bearer {api_key}",
    "Content-Type": "application/json; charset=utf-8"
}

# 文件保存
with open(filename, 'w', encoding='utf-8') as f:
    f.write(content)
```

### 2. API 调用优化
- 添加超时设置 (timeout=60)
- 错误重试机制
- 请求间隔控制 (避免限制)

### 3. 用户体验改进
- 进度条显示
- 彩色输出提示
- 详细错误信息
- 文件自动组织

## API 使用经验

### DeepSeek API 特点
1. **模型**: deepseek-reasoner 推理能力强
2. **限制**: 需要控制请求频率
3. **格式**: 对 JSON 格式要求严格
4. **中文**: 支持中文输入输出

### 提示词优化
```python
# 好的提示词特征
- 明确的格式要求
- 具体的字数限制
- 清晰的任务描述
- JSON 格式示例
```

### 常见问题
1. **返回格式不一致**: 添加格式验证和备选方案
2. **内容质量波动**: 多次尝试机制
3. **API 限制**: 请求间隔控制
