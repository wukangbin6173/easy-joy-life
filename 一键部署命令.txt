========================================
故障排查
========================================

如果编译失败：
- 检查 Java 版本: java -version
- 清理缓存: ./mvnw clean

如果服务启动失败：
- 查看详细日志: docker-compose -f docker-compose.prod.yml logs backend
- 检查端口占用: netstat -tlnp | grep 8080

如果 Git pull 失败：
- 配置 Git: git config --global http.postBuffer 524288000
- 或重新克隆: rm -rf /opt/easy-joy-life && git clone https://github.com/wukangbin6173/easy-joy-life.git /opt/easy-joy-life
