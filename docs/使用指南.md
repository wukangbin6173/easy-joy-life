# DeepSeek 小说生成器使用指南

## 快速开始

### 1. 环境准备
确保系统已安装 Python 3.7 或更高版本：
```bash
python --version
```

### 2. 安装依赖
```bash
pip install requests
```

### 3. 运行程序
```bash
python visual_novel_generator.py
```

## 使用流程

### 第一步：启动程序
运行后会看到欢迎界面：
```
============================================================
🤖 DeepSeek 可视化小说生成器
============================================================
```

### 第二步：输入小说设定
程序会依次询问：

1. **小说主题** (必填)
   - 例如：修仙者在现代都市隐藏身份，一边上班一边修炼
   - 例如：穿越到异世界的程序员用代码改变世界

2. **小说类型** (可选，默认：都市修仙)
   - 都市修仙、玄幻、科幻、悬疑、言情等

3. **章节数量** (可选，默认：15)
   - 建议 10-20 章，太多会耗时很长

### 第三步：等待生成
程序会显示详细的进度信息：

## 输出文件说明

### 目录文件
- `novel_outline.json` - 完整的小说目录，JSON 格式
- `raw_outline.txt` - 原始 API 响应（如果 JSON 解析失败）

### 章节文件
- `chapters/` 文件夹包含所有章节
- 文件命名：`第XX章_章节标题.txt`
- 每个文件包含完整的章节内容

## 常见问题

### Q: 程序卡在 API 调用不动？
A: 可能是网络问题或 API 限制，程序会自动超时重试。可以按 Ctrl+C 中断。

### Q: 生成的内容质量不满意？
A: 可以：
1. 修改小说主题，提供更详细的描述
2. 调整章节数量
3. 重新运行程序生成

### Q: 出现编码错误？
A: 确保：
1. 系统支持 UTF-8 编码
2. 使用支持中文的终端
3. Python 版本 3.7+

### Q: API 调用失败？
A: 检查：
1. 网络连接是否正常
2. API Key 是否正确
3. 是否超出 API 使用限制

## 高级用法

### 自定义配置
可以修改 `visual_novel_generator.py` 中的配置：

```python
# API 配置
API_KEY = "your-api-key"
MODEL = "deepseek-reasoner"

# 生成参数
max_tokens = 5000  # 每章最大字数
temperature = 0.7  # 创意程度 (0-1)
```

### 批量生成
可以创建脚本批量生成多部小说：

```python
themes = [
    "都市修仙者的日常生活",
    "穿越异世界的程序员",
    "未来世界的机甲战士"
]

for theme in themes:
    generator.generate_full_novel(theme)
```

## 注意事项

1. **API 限制**: 请合理使用，避免频繁调用
2. **生成时间**: 15章小说大约需要 30-45 分钟
3. **存储空间**: 每部小说约占用 1-2MB 空间
4. **网络要求**: 需要稳定的网络连接
