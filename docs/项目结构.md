# 项目结构说明

## 当前项目结构
```
DeepSeek-Novel-Generator/
├── 📄 visual_novel_generator.py    # 🌟 主程序 (推荐使用)
├── 📄 requirements.txt             # Python 依赖
├── 📄 readme.md                    # 项目说明
├── 📁 docs/                        # 📚 项目文档
│   ├── 问题分析.md                 # 乱码问题分析
│   ├── 项目经验总结.md             # 开发经验
│   ├── 使用指南.md                 # 详细使用说明
│   └── 项目结构.md                 # 本文件
├── 📁 chapters/                    # 📖 生成的章节 (运行后创建)
│   ├── 第01章_标题.txt
│   ├── 第02章_标题.txt
│   └── ...
├── 📄 novel_outline.json           # 📋 小说目录 (运行后生成)
└── 📁 legacy/                      # 🗂️ 废弃的尝试 (可删除)
    ├── novel_generator.py          # 早期 Python 版本
    ├── simple_novel_gen.py         # 简化版本
    ├── novel_generator.ps1         # PowerShell 版本 (有问题)
    ├── generate_outline.ps1        # PowerShell 测试
    ├── test_api.ps1               # API 测试脚本
    ├── run_novel_generator.bat     # 批处理文件
    ├── test_curl.bat              # curl 测试
    ├── simple_test.py             # Python 测试
    ├── 使用说明.md                 # 早期说明文档
    ├── 小说目录.txt                # 测试生成的文件
    └── 都市修仙小说目录.txt        # 测试生成的文件
```

## 文件说明

### 🌟 核心文件

#### `visual_novel_generator.py`
- **作用**: 主程序，完整的小说生成器
- **特点**: 
  - 可视化进度显示
  - 完善的错误处理
  - UTF-8 编码支持
  - 用户友好界面

#### `requirements.txt`
- **作用**: Python 依赖包列表
- **内容**: `requests>=2.25.1`

### 📚 文档文件

#### `docs/使用指南.md`
- **作用**: 详细的使用说明
- **包含**: 安装、使用流程、常见问题

#### `docs/问题分析.md`
- **作用**: 乱码问题的深入分析
- **包含**: 问题原因、解决方案、最佳实践

#### `docs/项目经验总结.md`
- **作用**: 开发过程中的经验总结
- **包含**: 技术选择、难点解决、优化建议

### 📖 生成文件 (运行后产生)

#### `novel_outline.json`
- **作用**: 小说目录，JSON 格式
- **结构**:
```json
{
  "novel_title": "小说标题",
  "genre": "类型",
  "total_chapters": 15,
  "chapters": [
    {
      "chapter_number": 1,
      "title": "章节标题",
      "summary": "章节概述"
    }
  ]
}
```

#### `chapters/` 文件夹
- **作用**: 存放所有生成的章节
- **命名**: `第XX章_标题.txt`
- **内容**: 完整的章节正文

### 🗂️ 废弃文件 (legacy/)

这些是开发过程中的尝试，由于各种问题被废弃：

- **PowerShell 脚本**: 编码问题严重
- **批处理文件**: 功能有限
- **早期 Python 版本**: 功能不完善

## 使用建议

### 🎯 新用户
1. 直接使用 `visual_novel_generator.py`
2. 阅读 `docs/使用指南.md`
3. 忽略 `legacy/` 文件夹

### 🔧 开发者
1. 查看 `docs/项目经验总结.md` 了解技术细节
2. 参考 `docs/问题分析.md` 了解已解决的问题
3. 可以研究 `legacy/` 中的失败尝试作为反面教材

### 📦 部署
1. 只需要核心文件：
   - `visual_novel_generator.py`
   - `requirements.txt`
   - `docs/` (可选)
2. 可以删除 `legacy/` 文件夹

## 清理建议

如果想要一个干净的项目，可以删除：
- `legacy/` 整个文件夹
- `小说目录.txt`
- `都市修仙小说目录.txt`
- 其他测试生成的文件

保留：
- `visual_novel_generator.py` (主程序)
- `requirements.txt` (依赖)
- `docs/` (文档)
- `readme.md` (项目说明)
