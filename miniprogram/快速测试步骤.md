# 🚀 5分钟快速手机测试

## 立即开始测试 (推荐方法)

### 第1步: 准备工作 ✅
- 确保手机和电脑连接同一WiFi
- 手机微信版本建议8.0以上
- 微信开发者工具已打开项目

### 第2步: 开始真机调试
1. **在微信开发者工具中**：
   ```
   点击顶部工具栏 → "真机调试" 按钮
   ```

2. **等待二维码生成** (约3-5秒)

3. **手机微信扫码**：
   - 打开微信 → 右上角"+" → 扫一扫
   - 扫描开发者工具的二维码
   - 点击"打开小程序调试"

### 第3步: 测试功能
当前小程序首页是测试页面，你应该能看到：
- ✅ "真机调试测试页面" 标题
- ✅ 一个蓝色的"点击测试"按钮
- ✅ 点击按钮会显示"点击成功！"

### 第4步: 测试其他页面
点击底部TabBar测试：
- 🏠 首页 (当前测试页面)
- 🏪 门店 (门店列表)
- 📋 订单 (我的订单)  
- 👤 我的 (个人中心)

## 🔄 如果真机调试失败

### 备用方案1: 预览功能
```
微信开发者工具 → 点击"预览" → 手机扫码
```

### 备用方案2: 检查网络
- 确认手机和电脑在同一网络
- 关闭电脑防火墙
- 重启微信开发者工具

## 📱 测试成功后的下一步

### 恢复正常首页：
如果测试页面能正常工作，可以恢复原来的首页：

1. **修改app.json**：
   ```json
   "pages": [
     "pages/index/index",        // 移到第一位
     "pages/test-simple/test-simple", // 移到后面
     // ... 其他页面
   ]
   ```

2. **重新编译测试**
