# DeepSeek 小说生成器使用说明

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 方法一：完整版（推荐）

运行 `novel_generator.py`，一次性生成完整小说：

```bash
python novel_generator.py
```

功能：
- 自动生成小说目录
- 逐章生成内容
- 自动保存到文件
- 章节间有连贯性

### 方法二：简化版

运行 `simple_novel_gen.py`，分步骤操作：

```bash
python simple_novel_gen.py
```

功能：
- 选择1：生成小说目录
- 选择2：生成单个章节

## 输出文件

### 完整版输出：
- `novel_outline.json` - 小说目录（JSON格式）
- `chapters/` 文件夹 - 包含所有章节文件

### 简化版输出：
- `小说目录.txt` - 小说目录
- `第X章_标题.txt` - 单个章节文件

## 使用建议

1. **首次使用**：建议先用简化版生成目录，确认满意后再生成章节
2. **批量生成**：使用完整版可以一次性生成整部小说
3. **自定义修改**：可以手动编辑生成的目录，然后用简化版逐章生成

## 注意事项

- 每次API调用间隔2秒，避免频率限制
- 生成内容为中文
- 章节长度约2000-3000字
- 支持多种小说类型（玄幻、都市、科幻等）
