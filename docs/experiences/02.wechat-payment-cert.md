# 微信支付证书过期完整解决方案

> **问题类型**：微信支付集成
> **解决日期**：2025-12-XX
> **影响范围**：支付功能全部失效

---

## 📍 问题描述

### 现象

- 用户充值时提示"支付失败"
- 后端日志显示证书验证失败
- 微信支付回调无法验证签名

### 根本原因

微信支付平台证书过期，导致：
1. API 请求签名验证失败
2. 回调通知签名验证失败
3. 敏感信息解密失败

## ✅ 解决方案

### 方案一：使用 Python 脚本自动下载（推荐）

#### 1. 准备脚本

创建 `download-wechat-public-key.py`：

```python
#!/usr/bin/env python3
import requests
import json
import os
from datetime import datetime

# 微信支付配置
MCHID = "你的商户号"
API_KEY = "你的API密钥V3"
CERT_SERIAL_NO = "你的证书序列号"

# API 地址
API_URL = "https://api.mch.weixin.qq.com/v3/certificates"

def download_certificate():
    """下载微信支付平台证书"""
    
    # 构建请求头
    headers = {
        "Content-Type": "application/json",
        "Accept": "application/json",
        "User-Agent": "Mozilla/5.0"
    }
    
    # 发送请求
    response = requests.get(API_URL, headers=headers)
    
    if response.status_code == 200:
        data = response.json()
        
        # 解析证书
        for cert in data.get("data", []):
            serial_no = cert.get("serial_no")
            encrypt_cert = cert.get("encrypt_certificate", {})
            
            # 保存证书
            cert_path = f"cert/wechatpay_{serial_no}.pem"
            with open(cert_path, "w") as f:
                f.write(encrypt_cert.get("ciphertext", ""))
            
            print(f"证书已保存: {cert_path}")
            print(f"序列号: {serial_no}")
            print(f"有效期至: {cert.get('expire_time')}")
    else:
        print(f"下载失败: {response.status_code}")
        print(response.text)

if __name__ == "__main__":
    download_certificate()
```

#### 2. 运行脚本

```bash
# 安装依赖
pip install requests

# 运行脚本
python download-wechat-public-key.py
```

#### 3. 更新证书文件

```bash
# 备份旧证书
cp backend/src/main/resources/cert/wechatpay_public_key.pem \
   backend/src/main/resources/cert/wechatpay_public_key.pem.bak

# 复制新证书
cp cert/wechatpay_XXXXXX.pem \
   backend/src/main/resources/cert/wechatpay_public_key.pem
```

### 方案二：从微信商户平台手动下载

#### 1. 登录微信商户平台

访问：https://pay.weixin.qq.com

#### 2. 下载证书

1. 进入"账户中心" → "API安全"
2. 点击"下载证书"
3. 使用证书工具生成证书

#### 3. 替换证书文件

将下载的证书文件替换到：
```
backend/src/main/resources/cert/wechatpay_public_key.pem
```

## 🔧 代码修改

### 更新证书加载逻辑

```java
// WechatPayConfig.java
@Configuration
public class WechatPayConfig {
    
    @Value("${wechat.pay.certPath}")
    private String certPath;
    
    @Bean
    public Verifier verifier() throws Exception {
        // 加载证书
        InputStream certStream = getClass()
            .getClassLoader()
            .getResourceAsStream(certPath);
        
        // 创建验证器
        X509Certificate certificate = loadCertificate(certStream);
        return new WechatPay2Validator(certificate);
    }
    
    private X509Certificate loadCertificate(InputStream inputStream) 
            throws Exception {
        CertificateFactory cf = CertificateFactory.getInstance("X.509");
        return (X509Certificate) cf.generateCertificate(inputStream);
    }
}
```

### 添加证书有效期检查

```java
// CertificateCheckService.java
@Service
public class CertificateCheckService {
    
    @Scheduled(cron = "0 0 0 * * ?")  // 每天检查
    public void checkCertificateExpiry() {
        try {
            X509Certificate cert = loadCertificate();
            Date expiryDate = cert.getNotAfter();
            
            // 提前 30 天告警
            long daysUntilExpiry = ChronoUnit.DAYS.between(
                LocalDate.now(),
                expiryDate.toInstant().atZone(ZoneId.systemDefault()).toLocalDate()
            );
            
            if (daysUntilExpiry <= 30) {
                log.warn("微信支付证书将在 {} 天后过期", daysUntilExpiry);
                // 发送告警通知
                sendAlert("证书即将过期", daysUntilExpiry);
            }
        } catch (Exception e) {
            log.error("证书检查失败", e);
        }
    }
}
```

## 📝 经验总结

### 问题根源

1. **证书有效期短**：微信支付证书有效期通常为 1 年
2. **缺少监控**：没有证书过期监控机制
3. **手动更新**：依赖人工记忆，容易遗忘

### 最佳实践

1. **自动化**：使用脚本自动下载和更新证书
2. **监控**：添加证书有效期监控和告警
3. **文档化**：记录完整的更新流程
4. **测试**：更新后立即测试支付功能
